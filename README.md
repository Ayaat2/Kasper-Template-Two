# Kasper Template

This is a responsive HTML & CSS template called **Kasper**, built as part of my learning journey in Front-End development.

I created this project with the help of **Eng. Osama Elzero** through his course. It was a great way to practice HTML and CSS by building a real template from scratch.

## Features

- Clean and modern design
- Responsive layout (mobile-friendly)
- Font Awesome icons
- Smooth sections and simple navigation
- Pure HTML5 and CSS3 (no JavaScript)

## Technologies Used

- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/)
